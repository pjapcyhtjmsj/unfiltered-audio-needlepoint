## Overview

Needlepoint models a classic 1970s passive EQ with an inductor/capacitor network, adding transformer harmonics and optional tube saturation for the warm, musical tone shaping prized in vintage hardware.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Unfiltered Audio Needlepoint** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Passive Network** | LC inductor-capacitor shelf and peak filter network simulation |
| **Transformer Model** | Input and output transformer harmonic distortion stages |
| **Tube Stage** | Optional triode saturation stage with bias control for warmth |
| **Impedance Match** | Adjustable input impedance affecting bass response and loading |
